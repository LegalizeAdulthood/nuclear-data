# ND812 Minicomputer

## Overview

The 12-bit **ND812**, produced by Nuclear Data, Inc., was a commercial minicomputer developed for the scientific computing market. Nuclear Data introduced it in 1970 at a price under $10,000 (about $77,000 in 2024 dollars).

**Type**: Minicomputer  
**Release Date**: 1970  
**Price**: $10,000 (1970)

# Architecture

The ND812 is a 12-bit, single-address, synchronous, sequential, parallel
machine using two's-complement arithmetic. The programming manual describes the
machine in four major functional units: control, arithmetic/logical, memory, and
input/output. The maintenance manual and board photographs show the physical
implementation as solid-state MSI/TTL register-transfer logic spread across
dense socketed boards, with the front panel exposing the switch register,
selected register, memory register, memory field lamps, run/interrupt state, and
manual load/start controls.

The central architectural idea is that core memory, the instruction path, and
the accumulator path are all 12 bits wide. Documentation numbers bit 0 as the
most significant bit and bit 11 as the least significant bit. A 12-bit word can
hold an unsigned value from 0 to 4095, a two's-complement value from -2048 to
2047, a single 12-bit instruction word, or two packed 6-bit characters.

## Register Model

The programmer-visible arithmetic state is richer than many contemporary
12-bit minicomputers:

- **J** and **K** are the two main 12-bit accumulators. They are the registers
  loaded from and stored to memory, used for programmed I/O transfers, and used
  for most arithmetic and logical results.
- **R** and **S** are 12-bit sub-accumulators. They are not directly loaded
  from or stored to core memory, but they can exchange with or contribute to
  operations involving J and K. Hardware multiply places its result in R and S.
- **PC** is the 12-bit program counter. It holds the address of the next
  instruction within the current memory field and is normally incremented after
  fetch.
- **IR** is the 12-bit instruction register. The control unit loads fetched
  instructions here and holds them during execution.
- **AR** is the 12-bit address register, also called MAR in the programming
  manual. It selects the current core location for instruction fetches and
  operand accesses.
- **MR** is the 12-bit memory data register. It supplies memory operands to the
  arithmetic path and holds data to be written to core.
- **MBR** is the memory buffer register at the core-memory interface. Its read
  data reaches IR and MR through the bus/MBR multiplexer; it also participates
  in restoring the contents of core after a read.
- **Status state** includes the flag bit, overflow bit, memory-field state,
  interrupt enables, and related status indicators. The status state is not a
  single programmer-visible general register, but it can be sampled into J or
  restored by status-oriented instructions.

## Core Memory and Addressing

The ND812 uses magnetic core memory with a 2 microsecond cycle time. The
brochure lists 8192 12-bit words as the common supplied memory, with a 4K
minimum and expansion to 16K in 4K increments. Because a 12-bit address selects
4096 words, larger memories are organized as memory fields. The PC, AR, and
instruction address fields select a word within a field, while field-control
state selects which 4K field is active for execution, subroutine linkage, and
interrupt handling.

Memory-reference instructions come in two major forms. Single-word memory
reference instructions use a 4-bit operation field, a direct/indirect bit, a
forward/backward displacement sign, and a 6-bit relative displacement. Two-word
memory-reference instructions add an absolute 12-bit address word and field
selection controls. This gives the ND812 both compact relative addressing and a
larger absolute-address form when the program needs it.

For instruction fetch, PC passes through the MX multiplexer and adder to the
summing bus, which loads AR. AR selects the core location; the word read from
core enters MBR and passes through the bus/MBR multiplexer into IR and MR.

The MX and TS multiplexers select the arithmetic operands. The adder/logic
result returns on the summing bus to J/K, PC, AR, or the bus/MBR multiplexer;
overflow logic updates OV. A load takes data from MR through TS and the arithmetic
path into J/K. A store takes J/K through the arithmetic path, summing bus, and
bus/MBR multiplexer into MR, which supplies the core write data. R/S exchange
data with J/K and supply operands to MX.

## Input/Output

The I/O system combines programmed I/O, interrupts, and DMA. Programmed I/O can
transfer 12 or 24 bits, receive 12 or 24 bits, or transmit and receive 12 bits
with one instruction. Single-word I/O instructions provide 256 possible I/O
commands; two-word I/O instructions provide 4096 possible commands. Four
instruction bits can also generate sequential peripheral-control pulses, which
lets a single I/O instruction perform multi-function device operations.

The ND812 includes a programmable 4-level priority interrupt system that can
trap to any core location in the first 4K words of memory. DMA is available
through the peripheral connector and cycle-steals memory cycles so devices can
read, load, increment, or decrement core memory directly.

## ND812 Compared With DEC PDP-8

The ND812 and the DEC PDP-8 are both 12-bit core-memory minicomputers built
around small instruction words, indirect addressing, front-panel operation, and
skip-based conditional control. They differ most strongly in the register model
and how much data movement hardware is provided in the base machine.

A former Nuclear Data Product Support Manager characterized the ND812 as a
"PDP-8 clone" adapted for real-time work. That description captures its market
position and programming style rather than literal hardware compatibility: the
ND812's multiple accumulators, addressing modes, and integrated arithmetic
distinguish it architecturally from the PDP-8.

| Aspect | ND812 | DEC PDP-8 |
|--------|-------|-----------|
| Word size | 12 bits | 12 bits |
| Main programmer registers | Dual main accumulators J and K, plus sub-accumulators R and S | One accumulator AC plus Link; optional extended arithmetic hardware on many systems |
| Arithmetic | Two's-complement fixed-point arithmetic; hardware multiply and divide were standard features | Two's-complement add/subtract through AC and Link; multiply/divide generally required optional EAE hardware or software routines |
| Memory addressing | Single-word relative direct/indirect references plus two-word absolute references with field selection | Page-oriented memory references to zero page or current page, with indirect addressing; extended memory used instruction and data fields |
| Memory size | 4K minimum, commonly 8K supplied, expandable to 16K in 4K fields | Typically 4K base, expandable with memory-extension fields; many PDP-8 family systems reached 32K words |
| Subroutine linkage | `JPS` stores the return address in the target location, then continues at the following word | `JMS` stores the return address in the target location, then continues at the following word |
| Conditional control | Extensive skip instructions for J, K, J/K combinations, overflow, flag, and memory tests | Skip-oriented OPR and IOT instruction groups built around AC, Link, device flags, and combined micro-operations |
| I/O and interrupts | Programmed I/O with 12/24-bit transfers, 4-level priority interrupts, and DMA support | Device-specific `IOT` instructions; interrupt and data-break capabilities varied by model and options |
| Architectural flavor | More register-rich and bus/multiplexer oriented, with standard multiply/divide and priority interrupt features | More minimalist base CPU centered on AC/Link, with many capabilities supplied by options or peripheral controllers |

In short, the ND812 feels like a PDP-8-class 12-bit minicomputer expanded in the
direction of richer arithmetic registers and more integrated I/O control. The
PDP-8 is the more minimalist design: elegant, smaller in the base programmer's
model, and strongly shaped by page addressing and microcoded operate groups. The
ND812 keeps the same 12-bit minicomputer economy but spends more hardware on
accumulator paths, hardware multiply/divide, memory-field control, and I/O
priority/DMA facilities.

## Programming Facilities

The ND812 did not have an operating system, just a front panel and run and halt switches. The I/O facility allowed for peripherals to directly load programs into memory while the computer was halted and not executing instructions. Another option was to enter a short loader program that would be used to bootstrap the desired program from a peripheral such as a teletype or paper tape reader. Since core memory is non-volatile, shutting off the computer did not result in data or program loss.

A number of system programs were made available by Nuclear Data for use with the ND812: BASC-12 assembler, symbolic text editor, NUTRAN interpreter, and disk-based symbolic text editor.

In the ND4400 analyzer system, users could program the ND812 in assembly
language or NUTRAN. FORTRAN became available later, although a former ND4400
user and Nuclear Data Product Support Manager recalled that the implementation
did not work very well.

## Instruction Formats

The instruction set consists of single and double word instructions. Operands can be immediate, direct or indirect. Immediate operands are encoded directly in the instruction as a literal value. Direct operands are encoded as the address of the operand. Indirect operands encode the address of the word containing a pointer to the operand.

### Single Word Instructions

| Bit Position | Field | Width |
|--------------|-------|-------|
| 0-3 | Operation | 4 bits |
| 4 | Direct/Indirect | 1 bit |
| 5 | +/- | 1 bit |
| 6-11 | Displacement | 6 bits |

The displacement and sign bit allow single word instructions to address locations between -63 and +63 of the location of the instruction. Bit 4 of the instruction allows for a choice between indirect and direct addressing. When the displacement is used as an indirect address, the contents of the location which is +/-63 locations from the instruction location is used as a pointer to the actual operand.

Many single word instructions do not reference memory and use bits 4 and 5 as part of the specification of the operation.

#### Literal Format

| Bit Position | Field | Width |
|--------------|-------|-------|
| 0-3 | Operation | 4 bits |
| 4-5 | Instruction | 2 bits |
| 6-11 | Literal | 6 bits |

#### Group 1 Format

| Bit Position | Field | Width |
|--------------|-------|-------|
| 0-3 | 0010 (fixed) | 4 bits |
| 4 | K register affected | 1 bit |
| 5 | J register affected | 1 bit |
| 6-7 | Shift/Rotate | 2 bits |
| 8-11 | Shift Count | 4 bits |

Group 1 instructions perform arithmetic, logical, exchange and shifting functions on the accumulator registers. This includes hardware multiply and divide instructions. Bit 4 is set if the K register is affected. Bit 5 is set if the J register is affected. Both bits are set if both registers are affected.

#### Group 2 Format

| Bit Position | Field | Width |
|--------------|-------|-------|
| 0-3 | 0011 (fixed) | 4 bits |
| 4 | K register affected | 1 bit |
| 5 | J register affected | 1 bit |
| 6 | Overflow | 1 bit |
| 7 | Complement Set | 1 bit |
| 8 | Complement Clear | 1 bit |
| 9-11 | Condition | 3 bits |

Group 2 format instructions test for internal conditions of the J and K accumulator registers, manipulate the overflow and flag status bits and provide complement, increment and negation operations on the J and K accumulator registers. Bits 9, 10 and 11 select the condition to be tested.

### Two Word Instructions

**Word 1:**

| Bit Position | Field | Width |
|--------------|-------|-------|
| 0-2 | Operation | 3 bits |
| 3-6 | Instruction | 4 bits |
| 7 | Indirect | 1 bit |
| 8 | K/J Accumulator | 1 bit |
| 9 | Change Fields | 1 bit |
| 10-11 | MF1, MF2 | 2 bits |

**Word 2:**

| Bit Position | Field | Width |
|--------------|-------|-------|
| 0-11 | Absolute Address | 12 bits |

Bit 9, Change Fields, inhibits the absolute address from referencing a different field than the one containing the instruction. When bit 8 is 1, the upper accumulator K is used with the instruction, otherwise the lower accumulator J is used. When bit 7 is 1, indirect addressing is used, otherwise direct addressing is used.

### Status Word Format

| Bit Position | Field | Width |
|--------------|-------|-------|
| 0 | Flag | 1 bit |
| 1 | Overflow | 1 bit |
| 2-3 | JPS (MF0, MF1) | 2 bits |
| 4-5 | Int (MF1, MF2) | 2 bits |
| 6 | IONL | 1 bit |
| 7 | IONA | 1 bit |
| 8 | IONB | 1 bit |
| 9 | IONH | 1 bit |
| 10-11 | Current Execution (MF1, MF2) | 2 bits |

The status register does not exist as a distinct register. It is the contents of several groups of indicators that are all stored in the J register when desired. The JPS and Int bits hold the current field contents that would be used during a JPS instruction or interrupt. The flag and overflow bits can be set explicitly from the J register contents with the RFOV instruction, but the other bits must be set by distinct instructions.

### Subroutines

The ND812 processor provides a simple stack for operands, but doesn't use this mechanism for storing subroutine return addresses. Instead, the return address is stored in the target of the `JPS` instruction and then the `PC` register is updated to point to the location following the stored return address. To return from the subroutine, an indirect jump through the initial location of the subroutine restores the program counter to the instruction following the `JPS` instruction.
