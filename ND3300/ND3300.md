# Series 3300 Multichannel Analyzer

The Nuclear Data Series 3300 was a modular multichannel analyzer and data
acquisition system for nuclear, medical and aerospace research. Its basic
configuration supported single- or dual-parameter analysis, magnetic core
storage, spectrum display, arithmetic processing and readout to external
recording devices. Plug-in modules and front-panel program plugs allowed
the same system to be configured for different experiments.

Nuclear Data's October 1967 NASA contract report describes a system
installed at the Electronics Research Center in Cambridge, Massachusetts,
with 4,096 channels of 20-bit storage, a 4-microsecond memory cycle and
16 MHz analog-to-digital converters. The component specifications
reproduced in the report describe the Series 3300 assemblies summarized
below. Capacities and facilities depended on the modules ordered.

## System organization

The system separated acquisition, data handling, memory and power into
interconnected assemblies. The Data Handling Main Frame provided a
signal-distribution frame, digital processing circuits and positions for
Master Control, Read-In/Out Control, Analog Display Configuration and
Storage Configuration modules. An additional module position could accept
a computer interface or automatic program sequencer.

## How it works

In pulse-height analysis, an ADC converts the amplitude of an accepted
input pulse into a numerical channel address. The acquisition logic and
storage configuration determine the corresponding memory location. The
system reads that channel's stored count, adds one and writes the updated
count back into core memory. Repeated events build a histogram of pulse
amplitudes. The controls also permit subtraction from stored data.

For dual-parameter analysis, the X and Y ADC results select a location in a
two-dimensional histogram. The storage program plugs divide memory into
power-of-two dimensions whose product fits the installed capacity. For
example, 4,096 locations can hold a 64 by 64 matrix; 16,384 locations can
hold a 128 by 128 matrix. Each location stores the count for one X/Y
combination.

The Data Handling Main Frame contains a 16-bit address register, a memory
register of up to 20 bits, a 24-bit data-processing register and a serial
binary adder. Fourteen address bits select memory locations; the remaining
two serve display functions. These circuits perform counting, arithmetic
and data-format conversion, while the separate System Memory Unit holds
the accumulated results.

## Acquisition modes

The ADC Program and Master Control modules support several ways of using
the acquisition hardware and memory:

* **Single parameter:** acquire a spectrum with either the X or Y ADC.
* **Dual parameter:** accumulate correlated X/Y measurements, optionally
  sampling the individual singles spectra as well.
* **Digiplex:** share memory between independent single-parameter spectra
  from the two ADCs, with internal or external control.
* **Spectrum multiscaling:** store successive pulse-height spectra in
  separate memory areas during successive dwell periods.
* **Routing:** share the X ADC among up to four inputs while keeping their
  data in separate storage areas.

The Master Control also selects pulse-height analysis or multichannel
scaling. Experiment timing can use clock time, live time or an external
time base; a meter indicates conversion losses. Automatic sequences can
stop after a preset interval, read out without erasing, or repeatedly
accumulate and read out destructively.

## Display, processing and readout

Stored data can be viewed as individual slices, a contour presentation or
an isometric display. The isometric view rotates through 360 degrees in
15-degree steps. Linear and logarithmic count displays, region-of-interest
intensification, blanking and overlapping spectra assist comparison. The
Scan Master expands a selected horizontal region by a factor of 10 to 20.
Quasi-random address scanning reduces flicker when displaying many
channels, including during acquisition.

Built-in processing includes integration, differentiation, multiplication,
spectrum transfer and stripping. A selected spectrum can be scaled and
added to or subtracted from another memory group. Front-panel controls
select groups and individual channels for display, processing or readout.

Readout interfaces include analog plotters, the IBM Model B output
typewriter, the ND-316 Autofinger/IBM 721 Selectric combination, Tally
paper-tape equipment and optional parallel printers. Magnetic-tape
transfers require an external controller and transport. Data can also be
read back from paper or magnetic tape. Paper-tape output normally uses
ASCII, with ASCII or IBM code selectable for paper-tape input. Readout can
include channel and group identification or only a selected region.

## Principal specifications

These figures describe the archived 1967 component sheets. Memory size,
word length and installed acquisition modules determine the configuration
of a particular system.

| Characteristic | Specification |
| --- | --- |
| ADC resolution | 128, 256, 512, 1,024, 2,048 or 4,096 addresses full scale; 12-bit address scaler. |
| ADC digitizing clock | 16 MHz, crystal controlled. Conversion time depends on pulse amplitude and selected gain. |
| ADC signal inputs | Direct nominal 0-10 V input; delayed nominal 0-10 V and 0-100 V inputs, with a 1.25-microsecond internal delay. |
| ADC linearity | Integral: better than 0.1%; differential: less than 1% deviation from mean channel width, over the top 99% of full scale. |

## Expansion

The NASA report describes expansion from two ADCs to eight, and from
single- or dual-parameter real-time accumulation to a buffered
magnetic-tape system for delayed accumulation of larger parameter sets.
These extended systems required additional modules. Other options included
replacement storage-conditioning modules, digital band selection,
region-of-interest selection and computer interfacing.

The magazine advertisement also promotes multiple-input multiscaling,
time-of-flight experiments, digital restriction gating and buffer-tape
modules. It advertises memory expansion to 32,768 channels; the archived
memory specification and the NASA report's general system description
document capacities only through 16,384 channels. The supplied sheets do
not describe the advertised 32,768-channel expansion.
